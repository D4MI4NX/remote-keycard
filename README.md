# remote-keycard
This plugin allows players to open keycard **doors**, **lockers**, **generators** and the **alpha warhead control panel** without the need to hold a keycard in their hand

## Installation
**Requirements:**

- A SCP:SL server
- [EXILED](https://github.com/ExMod-Team/EXILED/blob/master/.github/documentation/README.md#installation)

Download `RemoteKeycard.dll` from the latest release and move it into...

`~/.config/EXILED/Plugins` **(Linux)**

OR

`C:\Users\%UserName%\AppData\Roaming\EXILED\Plugins` **(Windows)**

\
Done.
